# WidgetForge

WidgetForge is Westmere Labs' open-source toolkit for building reproducible
dataset preparation pipelines.

## Release

The v1.0 release redistributes the following mirrored corpora:

- `openwebtext`
- `gsm8k`
- `wikipedia`

Before the public announcement, Legal runs a license review of every artifact
we redistribute. The tracking issue in this repository records the outcome.
