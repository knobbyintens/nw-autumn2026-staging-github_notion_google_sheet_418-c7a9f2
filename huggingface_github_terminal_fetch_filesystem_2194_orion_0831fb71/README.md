# Orion release workspace

Repository for the Orion-Synth-Instructions synthetic instruction release.

* The dataset card lives in [`dataset_card/README.md`](dataset_card/README.md).
* The generation pipeline configuration lives in `configs/generation.yaml`.
* Provenance of the synthetic responses is documented in `PROVENANCE.md`.
* Third-party model notices are in `THIRD_PARTY_NOTICES.md`.
