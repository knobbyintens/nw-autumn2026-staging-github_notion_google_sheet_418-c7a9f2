# Vendored licence texts

This directory contains the verbatim licence texts for the baseline checkpoints that are released
with, or evaluated on, the Orion synthetic corpus:

* `falcon-7b-LICENSE.txt` - Apache License 2.0
* `gemma-2-2b-it-LICENSE.txt` - Gemma Terms of Use
* `zephyr-7b-beta-LICENSE.txt` - MIT License

The licence of the hosted generator that produced the synthetic responses is not vendored here;
refer to its upstream model card as noted in `PROVENANCE.md`.
